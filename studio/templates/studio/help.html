Help

Workflow

  1. New Project — give it a title.
  2. Upload — add one or more images (JPEG, PNG, WebP, TIFF).
  3. Run OCR — choose Auto, Bangla, English, or Mixed.
  4. Editor — review, edit, save. Revisions are kept.
  5. Book design — pick a preset.
  6. Export DOCX — downloads a real editable Word file.

OCR language options

  • Auto — uses every installed Tesseract language.
  • Bangla only — requires ben language data.
  • English only — requires eng.
  • Mixed Bangla-English — requires both.

If a language is missing, you'll see an explicit error — never silent empty output.

What this app does not do

  • Handwriting Bangla OCR — no handwriting model is bundled.
  • PDF input.
  • Live page preview in the browser.
  • Background OCR queue — OCR runs synchronously.
  • Font embedding in DOCX — fonts are referenced by name only.

Diagnostics

Visit Settings to check Tesseract availability and current limits.
