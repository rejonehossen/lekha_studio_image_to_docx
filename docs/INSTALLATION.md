# Installation

## Requirements

- Python 3.10+ (3.12 recommended)
- Tesseract OCR binary (see OCR_SETUP.md)
- Bangla and English language data for Tesseract

## Windows

1. Install Python 3.12 from python.org (check "Add to PATH").
2. Install Tesseract from https://github.com/UB-Mannheim/tesseract/wiki — during
   install, tick "Bengali" under Additional language data.
