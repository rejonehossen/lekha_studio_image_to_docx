# OCR Setup

Lekha Studio uses Tesseract as the default OCR engine.

## Install Tesseract

- **Windows**: https://github.com/UB-Mannheim/tesseract/wiki — tick **Bengali**
  in the "Additional language data" section.
- **macOS**: `brew install tesseract tesseract-lang`
- **Linux (Debian/Ubuntu)**: `sudo apt install tesseract-ocr tesseract-ocr-eng tesseract-ocr-ben`
